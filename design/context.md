# V9 闭环产品设计上下文

## 目标

让现场工程师可靠完成真实任务，让运维管理员在云端管理真实记录、账号、设备、声纹、知识和技能，并让已授权技能和项目记忆可追溯地影响后续 AI 对话。

## 用户与场景

- 运维管理员：查看现场任务、失败证据和设备在线情况，签发或轮换设备凭据。
- 项目负责人：按项目、状态和时间追溯任务与完成结论。
- 远程专家与只读人员：仅查看获授权的任务证据，不执行管理操作。
- 现场工程师：在眼镜端建立/恢复项目、启用已授权技能、采集证据、确认任务结束、维护本人项目记忆与声纹授权。
- 超级管理员：管理组织、账号、角色、项目范围、设备、凭据、声纹撤销和审计。
- 流程设计人员：为不同工单配置受控步骤、字段、证据、分支和固定 HUD 页面模板，测试后提交审核。
- 流程审核/发布人员：检查安全、兼容性、真实连接器和验收用例，发布不可变版本并分配到项目、工单或规则。

## 成功标准

1. 已授权技能激活后，每一轮 AI 调用可证明使用了该版本和允许的知识范围；不可用时不伪造生效。
2. 每个项目的现场指令、事实、证据、结束摘要和恢复操作可追溯，且不会污染其他项目。
3. 管理员首屏识别同步异常、关联任务和最小恢复动作；账号、设备、声纹、知识和技能均有受权的真实管理流程。
4. V9 不改变眼镜 HUD；网页保持白雾灰绿、桌面高信息密度和可扫描的工作台结构；现有专家 Web 不改变。
5. 技能启用后的 AI 首 token p95 相比通用 AI 不劣化超过 150ms；双击声纹状态反馈 p95 小于 150ms；声纹分段结束到执行/明确失败的在线 p95 小于 3 秒。任何硬件资源、发热、耗电、掉帧或 ANR 回归阻断发布。
6. 不同工单可绑定不同的不可变工作流版本；眼镜从已验证本地快照切换普通步骤 p95 小于 100ms，断网/重启不丢当前步骤、表单草稿或证据。
7. 工作流编辑器只允许白名单节点、类型化变量和固定 HUD 模板；任意 URL、HTTP、脚本、客户端凭据或任意页面代码无法通过发布验证。

## 可配置工作流范围

- 必须支持说明、拍照、录像、表单、选择、语音填写、人工确认、AI 建议/检查、专家协同、条件分支、受控重试和结束节点。
- 管理端提供图形流程编排、属性配置、Air3 固定模板预览、样例数据模拟、校验、审核、发布、分配、回滚和审计。
- 眼镜只执行服务端编译、签名且客户端能力兼容的执行包；外部系统调用全部位于集成网关。
- 非目标：任意 UI 设计器、任意脚本/HTTP 节点、在眼镜保存第三方账号密码、由 AI 自动推进高风险动作、在 V9 重造完整 FSM/CMMS。
