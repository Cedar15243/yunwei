# V9 Skill/知识 ExecutionContext 验证

## 范围

- Supabase 权威清单进入 V9 网关的严格同步合同。
- 已发布、已授权 Skill 的任务级不可变快照。
- 授权知识引用、必需/可选知识策略和每轮本地授权复核。
- 清单过期、跨组织、未授权、知识过期和旧本地快照的明确失败。
- 设备 Skill API 不下发规则正文，任务结束时关闭 Skill/知识活跃快照。

## 固定模型

- 主 AI/视觉：`qwen3-vl-plus`。
- 实时 ASR：`fun-asr-realtime`。
- 声纹：讯飞 `s1aa729d0`。
- 本轮未引入 OpenClaw 或其他新增模型，也未修改 V8 历史默认值。

## 运行合同

- 网关生产路径要求权威清单；没有已同步清单、清单过期或必需知识不可用时返回 `503`，不调用模型、不回退本地假 Skill。
- 清单按组织、用户、设备和本地项目绑定，版本与 ETag 不可冲突或倒退。
- 激活任务时固定 Skill 版本和知识引用；后续清单的新 Skill/知识版本不替换活跃任务快照。
- 每轮 AI 只读取 SQLite 中已同步清单并复核当前授权、知识范围和有效期，不增加模型请求前的网络往返。
- 设备列表和启用响应只返回目录元数据，不返回 Skill 规则正文、知识正文或供应商密钥。
