- Android `versionCode`：`840`
- Android `versionName`：`8.0.40-marker-correction`

该包使用独立 `applicationId`，不会覆盖设备上保留的 `audit39` 稳定测试包。APK 与本地测试产物不提交到 Git。

## 修正内容

- 平台阶段只标注右侧温湿度报警列表，不框选下方机房环境检测区或整个屏幕。
- DDC 供电阶段只标注上方黑色端子区的 `10号 24VAC` 与 `11号 COM` 测量端，不框选黄色设备名称标签或下方 `1/2 S-BUS`。
- 网关阶段在同一张照片中只显示两个检测框：上方 `COM1/COM2 485通讯灯` 和下方 `RJ45网口通讯灯`；不框选 `PWR/RUN`、`A/B` 端子排或整台网关。
- 增加按演示阶段执行的检测标注白名单和同类框合并。视觉模型即使返回旧区域，HUD 也不会显示本阶段不允许的错误框。
- 内置受控参考图替换为现场确认照片，供低清、反光或模型无法稳定定位时提供演示辅助。

## 已知边界

- 检测框是现场辅助，不替代设备手册和持证工程师的安全测量判断；低清、倾斜、反光和遮挡仍会影响模型定位。
- 合成扬声器回灌场景中，云端 ASR 偶发用错误的短 final 覆盖已经正确识别的控制命令 partial。单独复跑可以通过，但仍需后续用定向测试收敛；不得用短命令回退逻辑覆盖较长的自由问答。
- 真人佩戴下的唤醒命中率、真实专家双向音视频及 20 分钟持续佩戴温升仍需现场人工验收。
