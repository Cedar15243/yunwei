## 本版重点

- 完善霍尼韦尔温湿度异常演示闭环：平台报警、现场架构、DDC供电、网关双通讯灯、传感器接线、平台恢复和维修记录沉淀。

- 返回首页或重新开始后创建新任务，未完成的演示任务不会污染普通AI对话。
- 提升离线“小叮当”唤醒在音频读取异常后的恢复能力，避免失效会话持续占用资源。
- 专家协同增加断线宽限、会话恢复、WebSocket心跳和刷新恢复；主动挂断才结束会话。
- 相机和短视频保持横向比例，现场照片、文字和AI回复继续保存在同一任务工作区。

## 安装方法

1. 在另一台电脑安装 Android Platform Tools，并连接已开启调试的 Air3。
2. 在命令行执行：

   ```powershell
   adb devices
   adb install -r DingdangAiOpsInvestor-v8.0.48-sensor-wiring-flow.apk
   ```

3. 眼镜中打开“叮当AI v8.0.48”。该版本使用独立包名，不会覆盖现有的 `audit47`。
