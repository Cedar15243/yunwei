# V9 长回复分页与步骤导航 Air3 验收计划

## 目标

在不改变现有 HUD 风格和布局的前提下，证明长回复分页、页码、底部操作区和维修步骤导航在 Air3 真机上互不遮挡、互不串线。

## 成功标准

- [x] 受控长回复在真实 WebView 中形成多页，所有页内容可按顺序重建且不丢失。
- [x] 每页正文 `scrollHeight <= clientHeight`，正文、页码和底部操作区边界不重叠。
- [x] “下一页”只改变对话页索引，不改变维修步骤。
- [x] 维修指导中的“下一页”不翻对话页，也不推进维修步骤，并给出正确提示。
- [x] “下一步”只推进一个维修步骤，不改变对话页索引。
- [x] V9.0.29 使用独立 `applicationId`，与 V8.0.48 和 V9.0.28 并存。
- [x] Android 回归、构建合同、APK 安全扫描、Air3 截图与 crash/ANR 检查通过。

## 停止条件

- 页面裁切、遮挡或命令串线时，先保存失败截图和 DOM 指标，再进入 TDD 最小修复。
- 音频、AI、专家协同或现有稳定 APK 出现回归时，不继续扩大范围。
