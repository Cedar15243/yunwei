# 设备任务同步设计

## 目标

让已登记的 Air3 设备将本地任务事件可靠同步到运维管理平台，供已授权网页后台按组织、项目和任务查看。同步不得改变眼镜 HUD、相机、音频、专家协同或现有会话 API。

## 身份与凭据

- 管理员为已存在的 `glasses_devices` 设备一次性签发随机设备令牌；数据库只保存令牌的 SHA-256 哈希。
- 凭据签发与轮换使用仅限 `super_admin`、`ops_admin` 的 `POST /management/devices/:deviceId/credentials`。响应只返回一次明文令牌和过期时间；轮换会在同一事务边界内撤销此前有效令牌。
- 令牌绑定单一设备。服务端由令牌查询设备、组织和 `assigned_profile_id`，不接受客户端提供的组织、操作者或数据库设备 ID。
- 未绑定操作者、停用设备、撤销/过期令牌均拒绝写入。令牌可由管理员轮换，旧令牌立即撤销。
- 眼镜通过应用私有文件保存令牌。令牌不进入 Git、日志、任务事件、网页或 APK 常量。

## 写入协议

- `POST /device-sync/events` 使用 `Authorization: Bearer <device-token>`。
- 请求只包含本地项目 ID、任务 ID、标题、事件类型、JSON payload、发生时间和幂等键。
- 服务端从设备绑定推导组织与操作者，按 `(organization_id, local_project_id)` 创建/复用项目，按 `(organization_id, local_task_id)` 创建/复用任务，并按 `(task_id, idempotency_key)` 写入事件。
- 重复事件返回成功且不产生第二条记录；无效字段返回 `400`，身份失败返回 `401`，未绑定设备返回 `403`。

## 客户端行为

- 当前 `TaskSyncEvent`、`TaskSyncQueue`、`TaskSyncClient` 保持本地优先、幂等去重和最多 60 秒退避。
- 运行时只在既有照片、保留视频、已最终化用户消息/AI 回复、步骤变化和任务完成成功后入队。
- 传输每次仅发送一个事件；网络失败不影响现有眼镜操作。视频上传留待下一阶段的预签名上传协议。

## 验收

1. 服务端测试覆盖未认证拒绝、停用/未绑定设备拒绝、组织隔离和重复事件去重。
2. Android 队列测试覆盖重复入队、重启恢复、首次重试和退避上限。
3. 接入不修改 HUD 冻结文件、专家协同页面或服务端。
4. Android 单测、Deno 测试与类型检查通过后，才构建候选 APK 并进行弱网真机验收。
