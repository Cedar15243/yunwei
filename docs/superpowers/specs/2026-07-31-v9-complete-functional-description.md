# V9 完整功能说明与性能非回归契约

## V9 目标

V9 是“AI 运维眼镜现场作业与云端管理平台”正式闭环版本。它让受权人员通过眼镜建立或恢复项目、使用真实发布的技能完成现场任务、形成可追溯项目记忆；云端管理账号、设备、证据、知识、技能、版本和审计。现有专家 Web、眼镜首页、HUD 视觉与稳定 APK 均受冻结保护。

## A. 用户、账号、权限与设备

1. 单一 `userId` 对应网页账号、眼镜操作者、项目授权、专家身份、设备绑定与声纹档案。
2. 组织隔离所有项目、任务、媒体、记忆、知识、技能和审计；每个查询/API 均由服务端执行 RLS 和角色校验。
3. 角色为超级管理员、运维管理员、现场工程师、远程专家、只读查看者。角色决定账号、设备、项目、媒体、知识、技能和审计的最小权限。
4. 云端人员管理支持邀请/创建、启用/禁用、角色和项目范围、设备绑定/解绑、审计与身份恢复。禁用后保留历史审计、撤销未来权限。
5. 设备管理显示设备状态、最近在线、绑定人员、MDM 策略版本、同步健康、技能版本；设备 token 仅在签发/轮换时显示一次，云端只保存哈希。

## B. 两种语音模式与声纹

1. 小叮当唤醒模式保留：唤醒后的一轮命令或提问，既有体验不改变。
2. 声纹监听模式由双击开启、再次双击关闭，与小叮当模式互斥。关闭后不录音、不转写、不上传、不执行命令。
3. 声纹模式下每段最终语音先做本人 1:1 验证；成功才可执行登记菜单命令或进入 AI。失败/超时/网络错误不切换模式、不执行命令、不伪造文本结果。
4. 相机、录像、专家通话占用音频时，监听主动暂停且不自动恢复；统一音频协调器确保任一时刻只有一个麦克风拥有者。
5. 眼镜现有 HUD 提供本人声纹同意、录入、重录、删除与状态；三段 6-10 秒自然中文录音创建模板并即时验证。管理员可查看/撤销，不可代替用户录入。
6. 三次连续失败锁定 60 秒。原始音频只在当前操作内存中存在，结果后清除；模板引用、同意版本、验证结果、设备绑定和审计由后端保存，密钥永不下发眼镜。

## C. 真实技能执行

1. 只有云端已发布、已分配给当前组织/人员/设备的 AI 运维技能可打开和启用。
2. 在眼镜端打开并启用技能，立即形成当前项目的不可变 `active_skill_snapshot`；HUD 显示名称、版本与授权状态。
3. 后续每轮 AI 对话经服务端 `SkillRuntime` 构建执行上下文，实际应用技能的适用条件、排除条件、步骤、阈值、SOP、补拍要求、风险、专家升级条件、知识范围与输出边界。
4. 技能由草稿、模拟验证、审核、发布、分配、观测、回滚组成；发布生成不可变版本，回滚重新分配旧版本，不改历史任务。
5. 技能关闭后新对话回到通用 AI；已产生的任务继续保留原技能版本。未授权/版本失效/后端不可用时明确拒绝，不显示假激活状态。
6. 技能不得下发任意代码、秘密、隐藏指令或危险命令。霍尼韦尔等现有演示技能只有在真实授权和语义命中时工作，普通问题仍走通用 AI。

## D. 项目、任务、AI 对话与项目记忆

1. 新建项目或关闭任务回首页后，下次输入必定新建任务；只有用户主动从项目记忆选择历史项目时才恢复。
2. 每个项目独立保存设备/型号、任务、文本、转写、图片、视频、AI 回复、确认/排除事实、风险、步骤、专家记录、技能/知识版本、摘要和审计。
3. 每轮 AI 由后端在同一执行请求中组装：平台安全规则、固定技能快照、项目事实/步骤/有效指令、已发布知识引用、最近对话、当前文本和证据。
4. 第一轮可短暂展示分析 HUD；第一个结果后保持在任务对话页。每条用户文本/转写/证据与对应 AI 回复可追溯配对。
5. AI 以自然现场指导回复，不强制固定八段模板。内容一屏容纳则完整显示；超出时按自然段、列表或维修步骤分页。翻页与下一维修步骤严格分离。
6. 任务动作包括下一步、已完成、异常、补拍、重新分析、呼叫专家。高风险动作需要二次确认。
7. 现场人员的明确未来规则，例如“以后这个项目遇到 X 按 Y 做”，写为带来源、条件、版本、创建者的 `project_instruction`，立刻可在项目记忆中查看、编辑、停用、删除和恢复版本。
8. AI 推测、普通闲聊、图片文本和外部资料不能自动写入持久记忆。项目指令仅影响本项目；人工审核后才能提升为组织知识或技能规则。

## E. 任务结束、项目记录、恢复、导航和设置

1. AI 建议结束不等于关闭任务。人工确认后显示结束摘要：完成步骤、遗留风险、证据、同步状态、技能/知识版本和下一步建议。
2. 结束页提供继续当前任务、确认结束回首页、查看/补充项目记忆、呼叫专家。确认结束写入真实 `task_completed`/`task_closed` 事件和项目摘要。
3. 既有菜单新增“项目记忆”和“设置”入口，不改变首页/ HUD 布局。项目记忆支持列表、搜索、筛选、时间线、恢复、状态、版本、风险和授权导出。
4. 恢复项目前显示恢复摘要和旧技能快照；用户确认才恢复。重新分析时才可比较/选用新发布版本。
5. 设置提供账号/设备绑定、声纹、语音模式、权限、同步网络、离线存储、技能/知识缓存、隐私/保留说明、应用版本和诊断；不显示 token、密钥、模板或原始音频。
6. 所有页面支持返回/返回首页；菜单首次打开、再次关闭；能力详情返回能力中心再回来源页面/首页；专家视频退出后恢复项目和步骤。

## F. 现场能力、证据、专家与知识库

1. 语音帮助按当前页面和语音模式给出有效命令；眼镜教学可语音进入和返回。
2. 巡检任务保留实训室和多行业可执行流程；设备记忆展示设备、品牌、数量和授权历史。
3. 照片、视频、音频和标注先本地持久化，再通过幂等队列上传；支持短时授权、校验、分片、续传、重试、取消和失败定位。
4. 专家协同继续使用现有独立视频页，V9 不修改其网页、服务、TRTC 或部署；只在项目记录中关联真实专家会话/批注事件。
5. 华方知识库提供目录、分类、文档、附件、检索、分页、草稿/审核/发布/归档/恢复、版本与审计。人工确认的案例可转知识草稿，不能自动成为结论。

## G. 云端管理平台与部署

1. 工作台显示真实在线眼镜、执行任务、异常同步、待处理专家请求、失败媒体和近期完成任务，并能钻取最小失败对象。
2. 项目/任务中心支持真实筛选、时间线、对话、步骤、AI 引用、证据、专家记录、完成结论与授权导出。
3. 人员/设备/声纹、媒体、知识库、技能、审计是独立受权工作区，均有加载、空、失败、重试与审计状态。
4. 管理 Web 使用独立云服务器目录、Docker 容器、回环端口、Caddy 站点和域名部署；发布前后验证既有专家站点健康且不重部署它。

## H. 速度、硬件与系统非回归契约

### 技能与 AI

- 技能清单/授权/版本在前台同步时预取并本地保存为已验证快照。用户打开技能只读本地快照，HUD 反馈目标 p95 小于 150ms，不额外等待网络。
- 每轮 AI 保持单次眼镜到 AI 后端请求。服务端在该请求内部从内存/数据库缓存解析技能、项目记忆和知识，不能在眼镜端增加“技能查询 -> 知识查询 -> AI”串行网络跳数。
- 服务端上下文解析目标 p95 小于 100ms，知识检索目标 p95 小于 150ms；在受控同网和同模型基线下，启用技能后的首个 AI token p95 相比通用 AI 不得劣化超过 150ms。超限时禁止发布该技能/版本。
- 后端不可用时技能请求明确失败并保留草稿、证据和重试，不回退成本地假规则；现有不使用技能的功能路径不得因此新增等待。

### 声纹与音频

- 小叮当模式和声纹关闭状态不启动声纹网络/CPU任务，不改变原唤醒链路、相机、专家音频或默认待机体验。
- 声纹开启后只使用一条 16kHz 单声道采集链和本地 VAD；不重复录音、不在 UI 线程编码、不在静音时上传、不后台持续持有资源。
- 语音转写候选与声纹验证采用同一采集片段并行准备；命令/AI 路由必须等待验证成功。不能为速度跳过验证或让未验证语音执行动作。
- 双击状态反馈目标 p95 小于 150ms；本人声纹命令从分段完成到成功执行/明确失败的在线 p95 目标小于 3 秒。若供应商、网络或 Air3 实测不能满足，声纹模式不作为正式默认功能发布。
- 相机、录像、专家通话优先级高于声纹。切换必须在 200ms 内释放/让出音频，不自动重开监听；20 分钟待机、连续会话、视频录制和专家通话不得产生 crash、ANR、持续录音或不可恢复音频占用。

### 发布性能门槛

- 先采集当前稳定 APK 的同设备、同网络、同流程基线，再对 V9 重复测量 UI、CPU、内存、温度、电池、帧时间、音频资源和首 token 时间。
- 任何核心路径出现统计显著回归、超预算、掉帧、发热、耗电异常、麦克风抢占、ANR 或持续后台采集，阻断发布并回到对应模块修复。
- 性能结论只使用当前 Air3 实机和当前云端构建产物，不能用模拟器、旧日志或演示结果替代。

## I. 不做的事

- 不修改或重部署现有远程专家网页/服务。
- 不改变已确认眼镜首页/HUD 视觉和布局。
- 不把声纹作为网页主身份认证或唯一高风险授权因素。
- 不开发华方派单、接单、签到、节点回写、二维码授权，只保留未来适配边界。
- 不在任何正式环境用假数据或不可执行入口包装成完成的产品能力。
